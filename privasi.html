Kebijakan Privasi penniq

Berlaku sejak 16 November 2026 · Read in English

Ringkasnya: penniq adalah aplikasi pencatat keuangan pribadi. Data keuangan Anda disimpan di perangkat Anda sendiri. Kami tidak memiliki server, tidak memasang iklan, dan tidak memakai alat pelacak. Cadangan ke Google Drive bersifat opsional dan hanya disimpan di Drive milik Anda sendiri.

1. Data yang Anda catat

Dompet, kartu kredit, kategori, anggaran, dan transaksi yang Anda masukkan disimpan di penyimpanan browser perangkat Anda (localStorage). Data ini tidak dikirim ke server pengembang, karena pengembang tidak mengoperasikan server apa pun untuk aplikasi ini. Pengembang tidak dapat melihat, mengakses, atau memulihkan data Anda.

2. Cadangan Google Drive (opsional)

Jika Anda memilih masuk dengan Google untuk mencadangkan data:

  • Aplikasi meminta satu izin saja: https://www.googleapis.com/auth/drive.appdata, yaitu akses ke folder tersembunyi milik aplikasi di Google Drive Anda. Aplikasi tidak dapat melihat atau mengubah file Drive Anda yang lain.
  • Satu berkas bernama penniq-cadangan.json berisi salinan data Anda ditulis ke folder itu, dan dibaca kembali hanya saat Anda menekan Pulihkan.
  • Berkas itu berada di Drive Anda sendiri. Pengembang tidak menerima salinannya dan tidak dapat mengaksesnya.
  • Token akses Google hanya disimpan sementara di memori aplikasi (berlaku sekitar satu jam) dan tidak ditulis ke penyimpanan maupun ke berkas cadangan.
  • Penggunaan dan pengalihan informasi yang diterima dari Google API oleh penniq mematuhi Kebijakan Data Pengguna Layanan API Google, termasuk persyaratan Penggunaan Terbatas (Limited Use). Data tersebut tidak dibagikan, dijual, dipakai untuk iklan, atau dibaca oleh manusia.

3. Layanan pihak ketiga yang berinteraksi dengan aplikasi

  • GitHub Pages menyajikan halaman aplikasi ini. Seperti server web pada umumnya, GitHub dapat mencatat alamat IP dan data teknis saat halaman dimuat. Lihat kebijakan privasi GitHub.
  • Google Fonts menyajikan huruf (Plus Jakarta Sans). Saat halaman dimuat, browser Anda meminta berkas huruf dari server Google, sehingga Google dapat menerima alamat IP Anda.
  • Google (Masuk dan Drive) hanya dihubungi jika Anda menggunakan fitur cadangan Google Drive.

Aplikasi tidak memuat iklan, analitik, atau pelacak pihak ketiga, dan tidak menggunakan cookie pelacakan.

4. Data yang disimpan di perangkat

Selain data keuangan, aplikasi menyimpan pengaturan tampilan, status cadangan (misalnya waktu cadangan terakhir), dan catatan teknis singkat untuk diagnosa login (tanpa token). Semuanya hanya ada di browser Anda.

5. Menghapus data dan mencabut akses

  • Menghapus data di perangkat: gunakan Atur → Data → Hapus semua data di aplikasi, atau hapus data situs ini lewat pengaturan browser.
  • Menghapus cadangan di Drive: buka Google Drive → Setelan → Kelola aplikasi → penniq → Hapus data aplikasi tersembunyi.
  • Mencabut akses Google: buka akun Google Anda → Keamanan → Aplikasi dan layanan pihak ketiga dengan akses ke akun → penniq → Hapus akses.

6. Anak-anak

penniq tidak ditujukan untuk anak di bawah 13 tahun, dan kami tidak dengan sengaja mengumpulkan data dari mereka.

7. Perubahan kebijakan

Jika kebijakan ini berubah, versi terbaru akan dipublikasikan di halaman ini dengan tanggal berlaku yang diperbarui.

8. Kontak

Pertanyaan tentang privasi dapat disampaikan lewat halaman Issues di GitHub proyek ini.

Privacy Policy (English)

Effective November 16, 2026

Summary: penniq is a personal finance tracker. Your financial data stays on your own device. We operate no server, show no ads, and use no trackers. Google Drive backup is optional and is stored only in your own Drive.

Data you enter

Wallets, credit cards, categories, budgets and transactions are stored in your browser's local storage on your device. This data is not sent to the developer; the developer runs no backend for this app and cannot see, access or recover your data.

Google Drive backup (optional)

  • The app requests a single scope: https://www.googleapis.com/auth/drive.appdata, which gives access only to the app's own hidden application-data folder in your Google Drive. It cannot see or modify your other Drive files.
  • One file, penniq-cadangan.json, containing a copy of your data is written to that folder and read back only when you tap Restore.
  • The file lives in your own Drive. The developer does not receive it and cannot access it.
  • The Google access token is kept in memory only (about one hour) and is never written to storage or to the backup file.
  • penniq's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Such data is not shared, sold, used for advertising, or read by humans.

Third parties

The page is served by GitHub Pages and fonts are loaded from Google Fonts, so those providers may receive your IP address and technical request data. Google is contacted for sign-in and Drive only if you use the backup feature. The app includes no advertising, analytics or third-party trackers.

Deleting data and revoking access

Use Settings → Data → Delete all data in the app, or clear this site's data in your browser. To remove the Drive backup, open Google Drive → Settings → Manage apps → penniq → Delete hidden app data. To revoke access, use your Google Account → Security → Third-party apps & services → penniq → Remove access.

Children

The app is not directed to children under 13.

Changes and contact

Updates will be published on this page with a new effective date. Questions: GitHub Issues of this project.

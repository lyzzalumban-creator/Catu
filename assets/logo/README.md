# Logo penniq

Kotak hijau neon (`#A8F552`, gradasi tipis) dengan dua mata maskot, sama seperti ikon di header aplikasi.

| Berkas | Dipakai untuk |
| --- | --- |
| `penniq-logo-google-120.png` | Logo di layar izin Google (Branding), 120×120 px |
| `penniq-ikon-1024.png`, `penniq-ikon-512.png`, `penniq-ikon-192.png` | Ikon sudut membulat, latar transparan (web, PWA, pratinjau) |
| `penniq-playstore-512.png` | Ikon Play Store: kotak penuh tanpa sudut, Google yang memotong sudutnya |
| `penniq-maskable-512.png` | Ikon PWA "maskable": mata diperkecil agar aman dari topeng bulat |
| `penniq-gelap-512.png` | Varian latar hitam, mata hijau |
| `*.svg` | Sumber vektor (`full`, `round`, `dark`, `maskable`) |

## Versi dengan tulisan "penniq"
Huruf: Plus Jakarta Sans 800 (sama seperti aplikasi). Di berkas `.svg`, huruf sudah tertanam (subset kecil) sehingga tampil sama di perangkat mana pun.

| Berkas | Dipakai untuk |
| --- | --- |
| `penniq-teks-google-120.png` | Logo di layar izin Google (Branding), 120×120 px, sudut membulat |
| `penniq-teks-ikon-512.png` | Ikon kotak bertulisan, sudut membulat, latar transparan |
| `penniq-teks-playstore-512.png` | Ikon kotak bertulisan untuk Play Store (kotak penuh) |
| `penniq-horizontal-latar-putih.png`, `penniq-horizontal-latar-hitam.png` | Logo ikon + tulisan di samping, 1230×420, dengan latar |
| `penniq-horizontal-terang.svg`, `penniq-horizontal-gelap.svg` | Versi horizontal berlatar transparan: tulisan gelap untuk latar terang, tulisan terang untuk latar gelap |
| `penniq-teks-bulat.svg`, `penniq-teks-penuh.svg` | Sumber vektor ikon bertulisan |

# Logo penniq

Kotak hijau neon (`#A8F552`, gradasi tipis) dengan dua mata maskot, sama seperti ikon di header aplikasi.

| Berkas | Dipakai untuk |
| --- | --- |
| `penniq-logo-google-120.png` | Logo di layar izin Google (Branding), 120×120 px |
| `penniq-ikon-1024.png`, `penniq-ikon-512.png`, `penniq-ikon-192.png` | Ikon sudut membulat, latar transparan (web, PWA, pratinjau) |
| `penniq-playstore-512.png` | Ikon Play Store: kotak penuh tanpa sudut, Google yang memotong sudutnya |
| `penniq-maskable-512.png` | Ikon PWA "maskable": mata diperkecil agar aman dari topeng bulat |
| `penniq-gelap-512.png` | Varian latar hitam, mata hijau |
| `*.svg` | Sumber vektor (`full`, `round`, `dark`, `maskable`) |
